# codex 模块结构说明

Codex × 守岸人 的全部逻辑都在本目录下，由 `main.cjs` 在启动时加载（`integration.cjs` 的 `setup()`）。

## 目录

```
codex/
├── integration.cjs       集成入口：托盘菜单、Codex 启动编排、主题与动画切换、用量播报
├── theme.cjs             主题控制器：CDP 注入，多主题分发（shorekeeper / midnight-deepseek）
├── theme-css.cjs         （旧路径，已移入 themes/shorekeeper/）
│
├── intros/               启动动画：把 mp4/webm/mov 丢进来即可在托盘里切换
│   └── default-shorekeeper.mp4   内置默认片（守岸人，约 12 秒）
│
├── themes/               界面主题：一个主题一个目录
│   ├── shorekeeper/            守岸人 · 夜海（半透明玻璃 + 立绘）
│   │   ├── theme-css.cjs       CSS 生成器（导出函数，接收 base64 资产）
│   │   └── assets/             avatar.png / background.png / render.png
│   └── midnight-deepseek/      深夜大肥鱼 · 雨夜（视频壁纸 + HUD）
│       ├── theme.json          主题配置（版本、天气源、HUD 尺寸）
│       ├── theme-css.cjs       CSS 生成器
│       ├── assets/             bg-loop.mp4（24 秒无缝循环）/ bg-poster.jpg
│       └── _backup_v1/         旧版备份（v1 的 theme.js 等，仅存档）
│
├── intro-main.cjs        启动动画子进程（独立进程，保留 GPU 解码）
├── intro-preload.cjs     动画窗口的渲染进程桥
├── intro.html / intro.js 动画页面与播放逻辑（定帧点按片长比例算）
│
├── panel.html/css/js     用量面板界面
├── panel-preload.cjs     用量面板的渲染进程桥
├── usage-service.cjs     用量服务（轮询、快照）
├── usage-stats.cjs       CC Switch / Codex 统计读取

│
├── assets/               通用小资源（面板头像等）
└── _archive/             归档：不再使用的旧素材（wallpaper-v1）
```

## 新增一个界面主题

1. 在 `themes/` 下建目录，例如 `themes/my-theme/`
2. 放 `theme-css.cjs`（导出 `(params) => cssString`）和 `assets/`
3. 在 `theme.cjs` 的 `THEME_IDS` 数组里加上 id
4. 在 `theme.cjs` 里加对应的 `xxxThemeExpression()`，并在 `themeExpression()` 里分发
5. 在 `integration.cjs` 的托盘「界面主题」子菜单里加一个 radio 项
6. 清理逻辑同步补进 `removeTheme()` 的元素 id 列表

主题资产统一用 `this.themeAsset(themeId, 相对路径)` 读取，结果会缓存成 data URI。

## 换一个启动动画

- 托盘「Codex 联动 ▸ 启动动画 ▸ 从文件导入…」：复制进 `intros/` 并立即启用
- 或手动把视频放进 `intros/`，再在托盘里选它
- 播不出来会回退到 `intros/default-shorekeeper.mp4`

## 注入机制要点

- 主题通过 CDP（`--remote-debugging-port=9227`）注入 Codex 页面，每 3.5 秒轮询一次
- 已注入时只发一条轻量 probe 语句，不重发几 MB 的 CSS / 图片 / 视频
- 视频壁纸以 base64 data URI 一次性注入（约 7.7 MB），之后由 probe 跳过
- 主题只改 CSS 变量与追加装饰层，不接管 Codex 的业务逻辑与数据
